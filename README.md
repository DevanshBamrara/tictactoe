# Tic Tac Toe - Python (Player vs Computer)

This is a simple command-line Tic Tac Toe game built with Python. The player plays as `X` and the computer plays as `O`.

## 🕹 Features

- 3x3 Tic Tac Toe board
- Human vs Computer gameplay
- Random AI (Computer makes random valid moves)
- Win, Lose, or Tie detection
- Clean and readable board UI in the terminal

## 🧠 How It Works

- The board is represented as a list of 9 elements.
- The user selects a position (1–9) to place their mark.
- The computer randomly picks a valid position on its turn.
- After each move, the game checks for a win or tie.

## ▶️ How to Run

```bash
python tic_tac_toe.py
